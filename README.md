# coralswap-core

Soroban smart contracts for the CoralSwap AMM protocol: factory, binary Pair,
LP token, router, and flash-loan receiver interface. Each pool contains exactly
two tokens; multi-asset pools are not currently supported. See
[ARCHITECTURE.md](ARCHITECTURE.md#pair) and the
[future multi-asset design note](docs/MULTI_ASSET_PAIRS.md).
